# Space Cut / Merge Spec

이 문서는 현재 메인 구현 설명이 아니라 예전 공간 분할/병합 설계 메모를 보관하기 위한 문서입니다.

## 현재 상태

- 메인 편집 흐름은 `RoomCreate` 중심입니다.
- `SpaceCut` / `Merge` 전용 모드는 현재 핵심 사용자 흐름이 아닙니다.

## 참고 용도

- 향후 room polygon 기반 분할 기능을 다시 넣을 때 참고
- virtual boundary 또는 다중 room 연산 규칙 재검토 시 참고

## 주의

- 여기 적힌 내용이 현재 코드와 1:1로 대응된다고 가정하면 안 됩니다.
